Module 09

Advanced AI — Beyond Classical ML

Neural networks are the same S.F.P.E. loop, run on GPU-accelerated tensors.

WhatNeural networks (weighted sums + non-linear activation) trained via PyTorch; plus pre-trained LLMs via API.
WhyClassical ML plateaus on unstructured data (images, text, audio). Deep learning learns its own features.
HowTensors replace arrays; backprop + gradient descent replace .fit().
Whenscikit-learn plateaus AND you have (a) lots of data, (b) unstructured data, or (c) a GPU.
WhereComputer vision, NLP, LLM API calls inside Python/GUI apps.
F.L.B.U.Forward · Loss · Backward · Update — the loop every neural net repeats
A note on this format: a real training loop needs PyTorch, tensors, and usually a GPU — none of which exist in a browser sandbox. There's no "Run" button here either; type this into a real Python environment (a GPU-backed notebook works well) to watch the loss actually drop.
import torch, torch.nn as nn

class SimpleNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer1 = nn.Linear(2, 8)
        self.layer2 = nn.Linear(8, 1)

    def forward(self, x):
        x = torch.relu(self.layer1(x))   # non-linear activation
        return torch.sigmoid(self.layer2(x))

model = SimpleNet()
loss_fn = nn.BCELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

for epoch in range(100):
    pred = model(X_train_tensor)         # FORWARD
    loss = loss_fn(pred, y_train_tensor) # LOSS
    optimizer.zero_grad()
    loss.backward()                      # BACKWARD
    optimizer.step()                     # UPDATE
