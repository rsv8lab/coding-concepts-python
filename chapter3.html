Pandas — Tabular Data

A DataFrame is a dict of NumPy arrays wearing labelled rows and columns.

WhatDataFrame (2D labelled table) and Series (1 labelled column) on top of NumPy.
WhyReal data arrives messy in CSV/Excel/SQL. Pandas is the standard load-clean-reshape tool.
Howpd.read_csv(), boolean masks, groupby(), merge().
WhenThe moment data has more than one "column" of meaning — almost always.
WhereFeeds Matplotlib/Seaborn (plots) and scikit-learn (X, y arrays).
L.F.G.M.Load · Filter · Group · Merge — the four verbs of real analysis
import pandas as pd

df = pd.read_csv("students.csv")                 # LOAD
high = df[df["gpa"] > 3.5]                     # FILTER: boolean mask

Read the concept table once

Notice: DataFrame = dict of NumPy arrays + labels. That one idea explains both its speed and its API.

2

Type the code yourself — no copy-paste

Type it, then replace "students.csv" with a CSV you actually care about. Run df.isna().sum() and df.dtypes first, every single time.

Those two lines prevent 80% of downstream ML bugs. Make them a reflex.
3

Load your CSV. Filter one meaningful condition. Group by one categorical column and compute a mean. Merge with a second small table if you can.
