Matplotlib & Seaborn — Seeing Data

Matplotlib is the engine; Seaborn is a statistical layer built for DataFrames.

WhatMatplotlib: low-level figure+axes. Seaborn: high-level statistical plots on DataFrames.
Why10,000 rows tell you nothing at a glance; a plot reveals distribution, outliers, relationships.
Howplt.subplots() for control; sns.histplot() / sns.pairplot() for one-liners.
WhenImmediately after cleaning (Module 3), before modelling (Module 8). Always look before you model.
WhereEDA, reporting, diagnosing a trained model's errors.
F.A.P.Figure · Axes · Plot — the hierarchy every Matplotlib call sits inside
import matplotlib.pyplot as plt
import seaborn as sns

fig, ax = plt.subplots(figsize=(6, 4))    # FIGURE = canvas, AXES = plot area
ax.plot(df['date'], df['gpa'])            # low-level: full control
ax.set_title("GPA over time")
plt.show()

sns.histplot(data=df, x='gpa', hue='department')  # ONE line
sns.pairplot(df[['gpa', 'hours_studied']])           # ONE line
