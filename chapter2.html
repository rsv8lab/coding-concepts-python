Module 02

NumPy — The Numeric Engine

Pandas, scikit-learn, and PyTorch are all built on top of the NumPy array.

Whatndarray: fixed-type, fixed-shape, contiguous grid of numbers.
WhyPython lists are slow for math; NumPy vectorises in compiled C — 100× faster.
Howimport numpy as np; operations broadcast element-wise without loops.
WhenAny time you do the SAME math across many numbers: means, distances, matrices.
WhereUnder every Pandas column and every scikit-learn model input.
S.B.I.Shape · Broadcasting · Indexing — the three ideas that unlock 90% of NumPy
import numpy as np

scores = np.array([88, 92, 79, 95])     # shape (4,)
curved = scores + 5                     # BROADCASTING: no loop needed
mean = scores.mean()                    # vectorised reduction -> 88.5

matrix = np.array([[1, 2], [3, 4]])     # shape (2, 2)
print(matrix.shape)                    # ALWAYS check shape when a bug appears
print(matrix @ matrix)                 # @ = matrix multiplication

Type it, run it in your own environment. Then deliberately break it: try np.array([1, 2]) + np.array([1, 2, 3]) and read the shape-mismatch error.

90% of NumPy errors are shape mismatches. Collect them — they're your best teachers.
