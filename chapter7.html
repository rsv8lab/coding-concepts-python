GUI — PySide6

Wraps any of Modules 1–6 in a clickable desktop application.

WhatA windowed interface (buttons, tables, plots) instead of a CLI script — built on Qt.
WhyNon-technical users won't run a .py script. A GUI turns your work into a tool.
HowThe EVENT LOOP: app waits idle; your code runs only in response to signals.
WhenOnce core logic (Modules 1–6) already works as plain functions. Build GUI LAST.
WhereInternal tools, data-entry apps, dashboards for non-coders.
W.I.S.H.Widget · Import · Signal · Handler — the four things every GUI feature needs
A note on this format: a real Qt window needs an actual window manager on your machine — it can't run inside a browser page. So there's no "Run" button on this chapter; type the code into a real Python file and run it locally to see the window.
import sys
from PySide6.QtWidgets import (QApplication, QMainWindow,
                                  QPushButton, QLabel, QVBoxLayout, QWidget)

# core logic: no Qt here, fully testable
def average_gpa(values):
    return sum(values) / len(values)

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self._build_ui()

    def _build_ui(self):
        self.label = QLabel("Click to compute average GPA")
        button = QPushButton("Compute")
        button.clicked.connect(self.on_compute)   # SIGNAL -> SLOT
        layout = QVBoxLayout()
        layout.addWidget(self.label)
        layout.addWidget(button)
        container = QWidget()
        container.setLayout(layout)
        self.setCentralWidget(container)

    def on_compute(self):
        result = average_gpa([88, 92, 79, 95])
        self.label.setText(f"Average: {result:.2f}")

app = QApplication(sys.argv)
window = MainWindow()
window.show()
sys.exit(app.exec())   # THE EVENT LOOP

1

Read the concept table once

The Golden Rule: core logic has ZERO Qt imports. GUI code only calls those functions. Separation of concerns is not optional.

2

Type the code yourself — no copy-paste

Type it, run it locally, click the button. Then break it: remove the connect() line and see that clicking does nothing. Put it back.

Every GUI bug traces back to "which signal fired, and what slot did it call?" Learn to ask that question.
3

Put your Module 3 Pandas filter and Module 4 chart behind a single button click. One QPushButton, one embedded Matplotlib canvas.

This is the highest-leverage exercise in the whole notebook — logic → GUI → visualisation, end to end.
